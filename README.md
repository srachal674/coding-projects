## Working in VS Code

Open `coding-projects.code-workspace` from a clone of this repository. It opens just this repository and disables automatic discovery of other repositories. Keep each project as a normal folder; do not initialize another Git repository inside it.

Saving updates your local file. Committing records the change locally. Pushing sends the commit to GitHub. In Source Control, verify that the repository is `coding-projects` before committing or pushing.
